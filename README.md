# 无声劫案 · 合作扑克行动

一款 3~6 人合作扑克游戏：全员用"筹码星数"当暗号传递自己牌型强弱的预估，四轮布局后按序亮牌——后亮的人牌型不能比前一位弱。全程无言，考验默契。

- **在线联机（微信小程序）**：各自手机，6 位房间号加入同一局
- **同屏热座（网页版）**：一部手机/一台电脑轮流操作

> 玩法机制参考了实体桌游的"暗号式合作"设计；名称、规则文案、界面均为原创。

## 目录

```
├── web/            网页版（单文件 index.html，浏览器直接打开）
├── miniprogram/    微信小程序版（在线联机 + 热座，需微信开发者工具）
├── test_game.js           网页版牌型引擎测试
├── test_mp_poker.js       小程序牌型引擎测试
└── test_online_flow.js    联机流程端到端模拟
```

## 快速开始

**网页版**：直接用浏览器打开 `web/index.html`。

**小程序版**：微信开发者工具导入 `miniprogram/`，联机功能需开通微信云开发并按 `miniprogram/README.md` 配置（环境 ID + 4 个集合的安全规则）。

## 测试

```bash
node test_game.js          # 网页版引擎（皇家同花顺/A低顺/骑士J/打手等 10+ 项）
node test_mp_poker.js      # 小程序引擎（与网页版逻辑一致性）
node test_online_flow.js   # 联机端到端模拟（含底牌隐私校验）
```

## 在线联机架构

房主权威模式：房主手机运行完整引擎，公开状态写 `rooms` 文档全员实时 watch；底牌写入 `hands` 私密文档（安全规则限定仅本人可读）；所有操作进 `actions` 馈送由房主按序消费。详见 `miniprogram/README.md`。
